Explicando as Tags HTML

"HTML é a linguagem de marcação padrão para criar páginas da web. HTML significa Hyper Text Markup Language."

O que são tags HTML?

As tags HTML são elementos que definem a estrutura e o conteúdo de uma página web. Elas são usadas para criar títulos, parágrafos, listas, links, imagens e muito mais.

Exemplos de tags HTML

Tags de Formatação

  • <h1> a <h6>: Usadas para criar títulos e subtítulos.
  • <p>: Usada para criar parágrafos de texto. Podemos citar como exemplo, a definição do que são tags html acima, aquilo é um parágrafo.
  • <mark>: Usada para destacar partes do texto.
  • <small>: Usada para criar texto menor.
  • <i>: Usada para criar texto em itálico.
  • <u>: Usada para criar texto sublinhado.
  • <strong>: Usada para criar texto em negrito.

Tags de Listas

  • <ol>: Usada para criar listas ordenadas.
  • <ul>: Usada para criar listas não ordenadas. Como essa lista que estamos criando.
  • <li>: Usada para criar itens de lista. Sem o <li>, <ol> e <ul> não funcionam corretamente.

Outras Tags

Tags de Citação e Links

  • <a>: Usada para criar links.
  • <blockquote>: Usada para criar uma citação em bloco. A citação acima é um exemplo disso.
Atributos

As tags HTML podem ter atributos que fornecem informações adicionais sobre o elemento. Por exemplo, a tag <a> pode ter o atributo href que define o destino do link e o atributo target que define onde o link será aberto.

Valores dos Atributos

Os atributos podem ter diferentes valores. Por exemplo, o atributo target pode ter os seguintes valores:

  • _blank: Abre o link em uma nova aba ou janela.
  • _self: Abre o link na mesma aba ou janela (padrão).
  • _parent: Abre o link na janela pai.
  • _top: Abre o link na janela principal, removendo quaisquer frames.

Tags de Formatação Adicionais

  • <hr>: Usada para criar uma linha horizontal.
  • <sup>: Usada para criar texto sobrescrito.
  • <sub>: Usada para criar texto subscrito.
  • <font>: Usada para definir a fonte do texto. Hoje em dia, é recomendado usar CSS para essa finalidade. Mais informações
  • <del>: Usada para criar texto apagado.

Tags de Abreviação

  • <abbr>: Usada para criar uma abreviação. HTML é a linguagem de marcação utilizada para criar páginas web.

Estrutura básica de uma página HTML

A estrutura básica de uma página HTML inclui os seguintes elementos:

  1. <html>: O elemento raiz que contém todo o documento HTML.
  2. <head>: Contém informações sobre o documento, como o título e metadados.
  3. <title>: Define o título da página que aparece na aba do navegador.
  4. <body>: Contém o conteúdo visível da página, como textos, imagens e elementos interativos.
